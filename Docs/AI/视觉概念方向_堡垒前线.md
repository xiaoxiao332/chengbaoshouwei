# 《城垒争锋》长期视觉概念方向

> 本文件记录 v0.4 及后续正式素材、场景与 UI 的视觉北极星。概念图定义最终效果，不以当前灰盒实现为审美基准；玩法与布局硬约束仍以 `AGENTS.md`、主策划和美术规范为准。

## 统一视觉语言

- 风格：高完成度 2D 卡通手绘；深暖灰粗轮廓、简化块面、少量笔刷纹理、左上柔光。
- 氛围：友方要塞温暖有秩序，连续战场开阔且有战争压力，敌方使用冷灰紫；整体轻松但不幼稚。
- UI：羊皮纸信息面、深木与深灰结构框、蓝色永久等级、橙金局内升级、金币纯金色，三种成长视觉严格分离。
- 识别：友方使用圆角盾徽和暖橙/米白；敌方使用尖角几何徽记和灰紫；中立 Boss 使用金铜与六边形语义。
- 禁止：旗帜、占领区、领地边界、皇冠、硬三路、敌墙后建筑、写实 3D、像素风、霓虹科幻 UI。

## 启动 / 加载画面

- Boot 仍是持久组合根；加载期间用于进度、转场与品牌定调，整备完成后停留为标题菜单，显示“开始游戏”和“设置”。
- 构图从暖色友方城镇过渡到开阔战场，再以冷灰紫敌墙收束；中央保留标题空间，底部只保留加载反馈。
- 正式制作时背景、标题、加载条必须分层；概念图中的文字不得直接作为运行时文字素材。

## Selection 布局

- 顶栏固定显示游戏标识、远征进度、金币与设置。
- 左侧分类栏约 11%，中央收藏约 52%，右侧战场选择约 33%。
- 收藏区使用四列卡牌；已解锁卡显示蓝色永久等级，未解锁卡保留剪影、锁、成本和前置条件。
- 右侧固定展示战场缩略图、Boss、三模式、敌方倾向与奖励倍率；右下为唯一主操作“开始战斗”。
- 背景采用低对比要塞作战桌、卡牌册和远景地图，只提供氛围，不抢 UI 信息层级。

## Gameplay 布局

- 世界空间严格遵循：城内九格 22% / 我方城墙 5% / 连续战场 68% / 敌方城墙 5%。
- 九格必须 3 × 3 一屏完整显示；友方城墙与敌方城墙均为单张纵向主体，敌墙后零建筑、零额外世界区域。
- 战场使用可自由穿越的上、中、下软通道；部署网格只在选兵时出现，Boss、陨石危险区、资源掉落、采集路线和箭塔工地始终可辨。
- 顶部资源按四组紧凑呈现，不显示金币；中央为双方墙血、时间、阶段与按需出现的 Boss 条；右上为暂停、倍速、设置。
- 底部卡牌托盘保持低矮和半重叠；选中卡只适度升起。建筑菜单朝战场侧弹出，不能遮挡建筑、资源条或托盘。

## 从概念图落地的规则

1. 概念图用于锁定构图、色彩、材质、信息层级和剪影，不作为可直接切片的运行时合图。
2. 正式背景不得包含城墙、建筑、单位、Boss、资源点、部署网格或 UI；所有玩法对象必须独立制作。
3. 中文标题、数值、按钮和说明在 Unity 中用授权字体与真实组件重建，避免沿用生成图中的字形误差。
4. 正式源件、`Formal/PNG`、Prefab 和 Scene 的验收都应与三张概念图并排检查，并固定满足 1920×1080 与 Safe Area。
5. 若概念图与玩法硬约束冲突，以玩法和布局规范为准，并在本文件记录视觉修订，不静默改变玩法。
