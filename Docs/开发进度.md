## 当前已实现

### 玩法、内容与表现

- 两张地图均为玩家安全点 3、中场候选 6、敌方安全点 3；安全点等墙距镜像。中场按 60/60/120/180/240/300 秒无放回激活，中场 45 秒、安全点 180 秒原位刷新。
- 奖励固定为建筑、不同建筑、资源、援军四槽；Common/Rare/Epic 只影响显式资源数量和既有援军模板。
- AI 只通过正式业务命令领取、替换、建造和部署，所有资源收支进入账本。
- 箭塔作为 `BattlefieldStructure` 进入双方建筑奖励池，但不能进入九宫格，只能由 `TowerConstructionSystem` 完成合法施工。
- 建筑资源短缺采用锁存停机与正式继续命令；升级按钮、权威升级进度、成功弹跳和失败抖动均已接入。
- Selection 卡牌图像由 CardCatalog → PresentationCatalog → ResourceKey 驱动，翻页和分类切换会同步刷新八个图像槽。
- Gameplay 奖励四槽、九宫格建筑状态、研究选项、中文展示名和 1920×1080 固定布局引用均已完成 Authoring 与回读。
- 城墙战斗已改为由冻结路线端点推导的纵向逻辑墙面（当前两图 `X=518 / 1824`）；单位按身体边缘射程停在墙外，同 Tick 进入射程即攻击，三路保持当前 Y。普通移动、友军分离和 Boss 击退统一限制单位身体不得越墙，墙体弹体命中对应墙面 X 与发射路线 Y；未增加 Collider、Prefab、场景字段或 Schema 字段。
- 炮车炮弹表现会在租用大炮世界 Prefab 时缓存查询根级 `point` 子物体，并在炮弹首次呈现时从该点坐标发射；敌方按当前朝向镜像发射点 X。权威弹道、命中、爆炸和伤害仍完全由 `CombatSystem` 的整数战场坐标决定，缺少 `point` 时安全回退到单位中心。

### 音频系统

- 已正式接入 11 首 BGM 和 2 个共享 SFX。BGM 为 44.1 kHz、Stereo、320 kbps MP3；受伤与采集音为 44.1 kHz、16-bit、Mono WAV。
- 13 个音频稳定地址均已注册到 `ResourceCatalog` 和 `Local-Audio`，并设置 `excludeFromGameObjectPreload=true`。
- `AudioPlaybackSystem` 由 `GlobalManager` 显式构造注册；运行时固定创建 2 个 BGM、4 个受伤和 2 个采集 `AudioSource`，没有新增单例、Service Locator 或热路径实例化。
- BGM 支持异步租约、0.75 秒交叉淡化和过时请求取消；按 Boot、Selection、地图阶段、Boss、胜负自动切换。
- Boss 结束后按当前真实阶段恢复地图音乐；胜负状态锁定到离开结算流程。
- 受伤音最多 4 声并发、每秒预算 6、突发 3；采集音最多 2 声并发、每秒预算 3、突发 2。超限请求直接丢弃，不排队。
- 同类并发按 `baseVolume / sqrt(activeCount)` 衰减；使用固定音高序列和战场 X 轴声像，避免消耗全局随机流。
- 士兵和采集者实际受到单体或范围伤害时发出一次受击事件；致死也只发一次。Boss、塔和墙不触发通用受伤音。
- 只有权威 `Harvest` 返回正数时才发采集完成事件；目标被外部耗尽、返回 0 时不播放。
- 应用设置 SectionVersion 为 3，包含主音量、BGM、音效和静音；默认值为 100%/70%/80%，支持旧版本迁移、范围限制和保存失败整体回滚。
- Settings Prefab 的 3 个 Slider、3 个百分比文本、静音与按钮引用均有效，并位于 Safe Area。
- 根目录 13 个原始音频已在 SHA-256 对比一致后删除。源文件备份保存在 `C:/Users/Administrator/AppData/Local/RampartRivals/AudioSourceBackup/20260831`；其中保留原始源文件 13 个，以及 2026-08-31 替换前的序章发展曲 1 个。
- `bgm_prologue_development_border_smoke.mp3` 已替换为新版并规范化为 44.1 kHz、Stereo、320 kbps；裁剪后未检测到持续 ≥30 ms 的首尾静音，SHA-256 为 `FA8EE7EF06ABA27F2C2BC659943A8A58DEEE8D376DBCC6D11E83123A397DC185`。稳定 GUID 和地址 `audio.bgm.prologue.development` 保持不变。

### TapTap / TapADN 激励广告

- TapADN Dirichlet Mediation Unity SDK 固定为 `5.1.2.3`；导入包 MD5/SHA-256 与 `AGENTS.md` 记录一致，官方 Samples 已移除。
- 只接入 ResultPanel 玩家主动触发的激励视频，不包含开屏、横幅、插屏或强制广告。
- Media ID、Media Key、奖励广告位 ID、隐私政策 URL 任一缺失时入口隐藏，SDK 不初始化。
- 奖励为本局完成奖励与胜利奖励经模式倍率后的 50%，不含首通奖励；按 `MatchId` 持久化且最多领取一次。
- 广告奖励保存失败会回滚金币；已验证状态允许重试领取而无需重看广告。
- Android Manifest 源清单只保留 `INTERNET` 与 `ACCESS_NETWORK_STATE`，并显式移除定位、电话、蓝牙和 Wi-Fi 状态权限。
- 当前 Media ID=0、Media Key 为空、Space ID=0、隐私政策 URL 为空，因此广告入口保持安全关闭。
