# 美术规范、UI 与场景布局

## 视觉方向

- 暖色手绘中世纪卡通，清晰剪影、适度描边、低噪声战场背景。
- 玩家使用橙/暖金，敌方使用紫色；稀有度使用棕金/蓝/紫。
- 背景图不得画入城墙、建筑、单位、资源点、Boss、部署区或 UI；玩法对象全部独立 Sprite/Prefab。
- 长期视觉北极星见 `AI/视觉概念方向_堡垒前线.md` 和 `ConceptArt/`。

## UI 层级

| 层 | Sorting | 用途 |
|---|---:|---|
| Bg | 0 | 背景 |
| Window | 100 | 常驻面板 |
| Pop | 200 | 四选一、研究、确认和结算 |
| Over | 300 | 加载、阻断、顶层反馈 |

Panel 根节点全屏拉伸；交互内容在 Safe Area 内。Prefab 保存锚点和子布局，运行时不得重建。

Gameplay 世界内容固定处于 Window UI 之下：背景 `10`、施工 `40`、单位 `50`、世界特效 `60`。常驻 HUD、卡牌托盘和卡牌提示框继续使用 `Window=100`，弹窗使用 `Pop=200`，阻断层使用 `Over=300`；世界实体和特效不得跨越到 100 以上。

## Gameplay 布局

- 左侧：玩家九格建筑区和玩家城墙。
- 中央：三条软路线、六个中场资源候选、Boss 和战斗。
- 右侧：敌方城墙；敌方设施不显示。
- 顶部：九资源、双方城墙、时间、暂停和速度。
- 底部：Soldier/Item 页签、卡牌托盘、部署和研究入口。

项目固定设计与验收分辨率为 1920×1080，不生成或维护其他宽高比的布局分支与验收图。

## 资源点

- 安全点靠近各自城墙，敌我等墙距；中场两列三行。
- 资源点使用自然轮廓，与部署区、兵种和携带物有明显层级差。
- 余量文本不能被单位或地形遮挡；耗尽/刷新反馈不改变权威坐标。

## 四选一面板

- `ChoicePanel` 位于 `ChoicePopCanvas`，override sorting 200。
- 固定 Choice0–Choice3：
  - Choice0/1：建筑图标。
  - Choice2：资源图标。
  - Choice3：援军图标和兵种组合。
- 四个槽位均保留 `img`；Choice0–2 不含 `ReinforcementVisual`，Choice3 唯一保留。
- 标题为“战后整备 · 四选一”。
- 标签显示“稀有度 + 玩家可读名称 + 具体内容”，禁止显示 CardId、ResourceId 或物理资源路径。
- 普通/稀有/史诗颜色分别为棕金、蓝、紫；颜色不能成为唯一识别方式。
- 四槽触控区不得重叠，图标保持比例且不裁切。

## Sprite 规范

- 运行 PNG：`Assets/Game/Art/Formal/PNG/`。
- Schema v14 奖励图标：
  - `SchemaV14/icon_reward_building.png`
  - `SchemaV14/icon_reward_resource.png`
  - `SchemaV14/icon_reward_reinforcement.png`
- 奖励图标：透明背景、无文字、暖色中世纪卡通；Sprite 2D/UI、Single、Max Size 256、MipMap Off、Clamp、Alpha 保留。
- 地图背景为不透明 1920×1080；单位/建筑/图标保持透明边缘。
- 修改正式图片后必须检查 Alpha、裁切、比例、Importer、GUID、Addressables 和 Prefab 引用。

## 卡牌和单位表现

- 卡牌图标表达类型，文本表达名称/费用/作用；不要把完整说明塞进图标。
- 单位以武器和轮廓区分职责；玩家/敌方换色不能破坏可读性。
- 援军组合最多显示三个单位槽和数量；空槽隐藏。
- 建筑蓝图复用真实 Sprite，以半透明颜色表达合法/非法，不制作另一套玩法图。

## 动画与遮挡

- 程序动画只作用于 Visual/Pivot 子节点，不覆盖权威根位置和缩放。
- 九宫格每个 `BuildingArt` 顶部共用同一条带位置：建造反馈使用蓝色 Slider，落位后以非缩放时间从 0 填充到 1000 并在 1 秒后隐藏；该进度只用于表现，建筑仍按业务事务立即生效。
- 升级期间改用橙金色 Slider，并直接显示权威 `UpgradeProgressMilli`；升级结束后隐藏。两个 Slider 均无 Handle、不可交互，默认隐藏。
- 已升级建筑在右上角持续显示约 30×30 的暖金色向上尖角图标；未升级或空槽默认隐藏，二升三期间保持显示。图标资源为 `Assets/Game/Art/Formal/PNG/state_building_upgraded_chevron.png`，深棕描边、透明背景、Sprite/Single、Max Size 128、MipMap Off、Clamp。
- 升级按钮反馈只作用于 `UpgradeAction/FeedbackPivot`：成功约 0.42 秒，暖金闪烁并按 `1 → 1.15 → 0.97 → 1` 弹跳；失败约 0.42 秒，红色闪烁并横向抖动约 ±10 px；均使用非缩放时间且允许中断重播，不移动菜单或其他按钮。
- 非满级且未处于升级中的建筑始终允许点击中间“升级”按钮；正式升级事务成功时播放成功反馈，资源、工作次数或阶段条件不足等事务拒绝均播放失败反馈。升级中和满级时按钮不可点击。
- 世界排序保证城墙、资源点、单位、弹体、携带物和工地关系稳定。
- 粒子、伤害数字和路径提示不能遮挡部署区和 ChoicePanel。
- 弹体/爆炸视觉结束后必须随租约回收，不能残留在切场景后。

## 验收

- 1920×1080 检查 Safe Area、四槽、九格、卡牌托盘、研究和结算。
- 建筑验收同时检查建造条 1 秒后隐藏、升级条跟随权威进度、`Level > 1` 图标持续显示，以及资源不足时只有升级按钮播放失败反馈。
- 四选一标题、四个图标、中文文案、稀有度、触控区和 Choice3 组合信息可读。
- 世界实体不穿透 Pop 面板；背景不含玩法对象；Sprite 无白边/黑边。
- 验收截图只保存当前 Schema v14 最终通过版本，登记于 `ValidationScreenshots/README.md`。
